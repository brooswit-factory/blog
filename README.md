# blog

Blog for Brooswit Factory, served at https://blog.brooswit.nexus by GitHub Pages from `main`. Currently an "Under construction" placeholder. The text area sits on a dark panel with a stone border on both sides (`assets/border.png`, right side mirrored; copied from the website repo). No build step: edit `index.html`.

## Changes

Every change bumps `version` in `package.json` (semver) and adds an entry to `CHANGELOG.md`. CI fails a PR that does not.
